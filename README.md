# Common vendor blobs for Xiaomi SM8750 devices

Proprietary files shared by Xiaomi SM8750 devices, from HyperOS 4 China
`OS4.0.0.44.XPYCNXM`, pulled with `extract-files.py` from the
[common device tree](https://github.com/xiaomi-pad-8-pro-development/android_device_xiaomi_sm8750-common).

Goes in `vendor/xiaomi/sm8750-common`.
